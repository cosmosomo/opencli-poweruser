# V2EX 适配器经验

> 验证日期：2026-09-17（探针批次）
> 版本：opencli v1.8.7
> 状态：**精简版，待完善**。仅记录 09-17 AntiGravity 委托探针批次的实测发现。

## 认证方式

COOKIE 策略。V2EX 部分节点需登录才能查看完整内容。

登录验证：`opencli v2ex whoami -f json`

## 已验证可用命令

| 命令 | 用途 | 示例 | 状态 |
|---|---|---|---|
| `node <name>` | 读取指定节点的帖子列表 | `opencli v2ex node jobs -f json` | ✅ |
| `hot` | 热门帖子 | `opencli v2ex hot -f json` | 待实测 |
| `topic <id>` | 读取帖子详情 | 待实测 | 待实测 |

**⚠️ 无 search 命令**：V2EX 适配器没有 search，只能按节点泛读 + 人工筛选。

## 关键发现（2026-09-17）

### 无 search，只能按节点泛读（P2）

V2EX 适配器确实没有 search 命令。采集策略：
```
按节点泛读（jobs/programmer/share/work）→ 人工筛标题 → topic 精读
```

### 节点内容定位

| 节点 | 内容 | 求职相关度 |
|---|---|---|
| `jobs` | 招聘信息（以社招远程岗为主） | 中（校招密度低） |
| `programmer` | 程序员技术讨论 | 中（AI/Agent 讨论活跃） |
| `share` | 分享创造 | 低 |
| `work` | 工作相关 | 中 |

09-17 实测：jobs 节点有远程岗（测试 15-22K、量化 30-50K、AI 产品总监上海），但**校招密度低**，建议降级为巡检渠道而非主力采集渠道。

## 反爬风险评估

**低**——V2EX 对读取接口限流宽松。
